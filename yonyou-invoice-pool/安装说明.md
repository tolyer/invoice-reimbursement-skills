# yonyou-invoice-pool 安装说明

> **当前版本：0.3.2（2026-10-23）**　变更历史见 `CHANGELOG.md`
> 0.3.2 **没有加功能，只加纪律**：新增 `references/状态断言与收敛.md`，把「出错之后无限重试」
> 这个问题按死——三断言、禁坐标定位、上传必回读文件名、单动作 3 次预算。
> 起因是一次复盘：22 分钟打了 106 个脚本，真正推进业务的只占 8.5%。
> 0.3.1 用一份脱敏票袋（6 行 / 16 份附件）全流程跑通，补了票袋命名字符限制、
> 附件串行修正、未分组票袋搬运等六个坑。

> （「归档清单.md」这种名字旧版认不出）、字段定位改用 `fieldid`。
> **请勿使用 0.3.1 及更早版本。**

把**一个**结构化发票目录，完整搬进用友云（YonBIP）发票池的**一个**新建票袋。
只做票袋，不碰报销单表头、不关联事项申请、不提交。

## 一、安装

### 方式 A：解压到用户级 skills 目录（推荐，所有项目可用）

```bash
# macOS / Linux
unzip yonyou-invoice-pool.zip -d ~/.workbuddy/skills/

# Windows PowerShell
Expand-Archive yonyou-invoice-pool.zip -DestinationPath "$env:USERPROFILE\.workbuddy\skills"
```

装完确认目录结构：

```
~/.workbuddy/skills/yonyou-invoice-pool/
├── SKILL.md                     # 主入口：工作流 + 硬性规则
├── CHANGELOG.md                 # 版本更新记录
├── 安装说明.md                   # 本文件
├── references/
│   ├── 状态断言与收敛.md          # 录入时的防打转纪律（0.3.2 新增，必读）
│   ├── 平台操作手册.md
│   ├── 目录解析与字段口径.md
│   └── 复核与交付.md
└── scripts/
    └── scan_invoice_dir.py
```

### 方式 B：只给当前项目用

解压到项目目录的 `.workbuddy/skills/` 下即可。

## 三、输入的发票目录必须长这样

```
发票目录-0720-0806/
├── 01-飞机含专车-HKD2873.00/
│   ├── ★票据本体/
│   │   └── QQ邮箱-机票订单确认¥2484.pdf
│   └── ☆附件/
│       ├── 01-支付截图.PNG
│       └── 02-行程单.pdf
├── 02-住宿3557-HKD2606.14/
│   ├── ★票据本体/ …
│   └── ☆附件/ …
└── 报销材料核验台账-0720-0806.md   （可选，有则优先取日期/发生地/备注）
                                    ⚠️ 也可能叫「归档清单.md」——脚本会列为待确认候选
```

规则：
- 每行一个文件夹，命名 `NN-描述-HKD金额`；
- 夹内两级：`★票据本体/`（**只能 1 个文件**）和 `☆附件/`（可多个）；
- 目录还不是这个结构？先用 `invoice-organizer` skill 整理，别硬上。

## 四、怎么用

对话里直接说：

```
用 yonyou-invoice-pool 把 <发票目录路径> 录成票袋 <票袋名称>
```

它会：

1. 跑脚本解析目录，生成《票袋录入计划》（逐行清单 + 文件清单 + 数据缺口）；
2. **停下来等你确认**——没点头绝不动浏览器；
3. 确认后建票袋 → 逐行录入 → 传票据本体和附件 → 保存；
4. 交付逐行台账 + 单页 HTML 报告。

## 五、七条最贵的坑（先记住能省两小时）

1. **只点「保存」，绝不点「保存为草稿」**
   草稿只进草稿箱，不落票袋，列表页搜不到，等于白干。

2. **票袋名只能写中文 + 英文字母 + 数字**
   连字符、括号、空格、下划线都会被平台红条拒绝
   （「票袋名称只能包括中英文字和数字」）。写 `日期范围城市用途HKD金额`，别写 `日期范围-城市-用途(HKD金额)`。

3. **文件上传别用 Playwright 的 `setInputFiles()`**
   在这个平台会直接挂起。改用 JS 注入 `DataTransfer` + `dispatchEvent('change')`，
   代码见 `references/平台操作手册.md` 第 5 节。file input 不在表单容器里，
   要**全局** `document.querySelectorAll('input[type=file]')` 找 `[multiple]` 那个。

4. **失焦用 `Tab`，别点页面空白**
   点空白处等于关闭「票据明细」弹窗，未保存的日期/金额/备注全丢。

5. **日历会记住上一次的月份视图**
   每次打开日历先读 `.wui-picker-month-btn` 校验月份再翻，**别写死「翻 N 次」**——
   写死过一次，把 2026-09-20 录成了 2026-08-20。同理，两个单选（账单类型 / 消费类型）
   都可能静默点不动，各回读一次 `checked` 再点下一步。

6. **消费类型别想当然**
   携程用车、滴滴 → **网约车**；只有 Grab / 出租车 → **其他交通**。
   记反了整行类型就错，财务退单。

7. **出错后最危险的动作是「重开」**
   关掉弹窗重来、删掉账单重录、原样再跑一遍脚本——这三件事都会把页面推回**出问题的那个起点**，
   于是同一个错误反复复现。实测 22 分钟打了 106 个脚本，只有 8.5% 在推进业务。
   正确做法：先回读三件事（弹窗层数 / 左栏选中票袋 / 目标行金额），哪不对就地修；
   单动作 3 次、单行 8 个脚本为上限，超了就停下说清楚卡在哪。
   详见 `references/状态断言与收敛.md`。
