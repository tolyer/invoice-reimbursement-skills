# 目录解析与字段口径

> 本文件可由用户手工维护，改动下次执行即生效。

---

## 一、结构化目录约定

由 `invoice-organizer` skill 归档产出的标准形态：

```
发票目录-<行程区间>/
├── 01-飞机含专车-HKD2873.00/
│   ├── ★票据本体/QQ邮箱-机票订单确认¥2484.pdf
│   └── ☆附件/01-...png  02-...pdf  03-...pdf
├── 06-补助-HKD9996.00/
│   ├── ★票据本体/说明-手录行程无票据本体.txt   ← .txt = 声明"无票据本体"
│   └── ☆附件/01-SCR-...-Google汇率USD7.84.png
└── 报销材料核验台账-0720-0806.md                ← 字段来源，优先级最高
```

| 元素 | 规则 |
|---|---|
| 行目录名 | `NN-描述-HKD金额`，如 `02-住宿3557-HKD2606.14` |
| `★票据本体/` | 该行唯一的核心凭证，**只取 1 个**（平台只允许 1 张） |
| `☆附件/` | 全部原始材料，`NN-内容-金额.扩展名` 编号排序，逐个全传 |
| `.txt`/`.md` 说明文件 | 出现在 `★票据本体/` 时表示**无票据本体**，不上传 |
| 台账 | 目录内或父目录含「台账/核验/ledger」的 md/xlsx/csv，**优先作为字段来源** |

**若用户给的不是这个结构**（散装文件夹、Downloads 原始文件），先转 `invoice-organizer` 做识别归档，
不要直接开录。

## 二、用脚本解析（第 1 步必做）

```bash
python3 ~/.workbuddy/skills/yonyou-invoice-pool/scripts/scan_invoice_dir.py \
  "<发票目录>" --out 票袋录入计划.md --json 票袋录入计划.json
```

脚本自动产出：逐行清单（类型/金额/原币/汇率）、文件上传清单、待确认缺口。
**脚本只读取文件，绝不移动/重命名/删除。**

### 可自动推导 vs 必须人工给

| 字段 | 可否从目录推导 | 来源 |
|---|---|---|
| 账单类型、消费类型 | ✅ 目录描述关键词 | 见下表 |
| 含税金额（HKD） | ✅ 目录名 `HKDxxxx` | |
| 原币币种 | ✅ 文件名 `¥`/`MYR`/`USD`/`HKD` 线索 | |
| 汇率 | ✅ 附件名 `CNY0.8646`/`MYR1.93`/`USD7.84` | |
| 票据本体 / 附件路径 | ✅ | |
| **开票日期** | ❌ | 台账 → 用户确认 |
| **发生日期** | ❌ | 台账 → 用户确认 |
| **发生地** | ❌ | 台账 → 用户确认 |
| **备注** | ❌ | 台账 → 用户确认（含换算公式） |

**日期/发生地/备注三缺一不停手**——先把缺口列全，一次性问用户，不要边录边问。

## 三、字段口径（与报销单侧保持一致）

完整版见 `~/.workbuddy/skills/invoice-organizer/references/报销单填写逻辑.md`，此处摘录票袋录入必需项。

1. **开票日期**：CNY 消费填提交前一天；HKD 原生 / Grab 对账单填实际出单日；补助（手录）填**出发日**。
2. **发生日期**：实际消费发生日——入住日、乘坐日、Grab 首末笔区间、补助填**返回日**。
   - Grab 行只有单个日期字段，区间口径取**末笔日期**（既有做法），若财务另有口径以用户为准。
3. **账单币种**：一律「港币」，金额填折算后的 HKD 数值。
4. **发生地**：城市名（吉隆坡 / 深圳）；手录行程无此字段。
5. **备注**：必须含换算公式「原币金额/汇率=HKD金额」。
   - CNY 用**除法**（`2484/0.8646=2873`），MYR/USD 用**乘法**。
   - 风格：中文逗号、无空格、小写航班号。
   - 例：`去程zh327,深圳~吉隆坡(含0720携程专车送机),回程zh328,吉隆坡~深圳,汇率为2484/0.8646=2873`
6. **票据本体判定**：谁能独立证明这笔消费，谁就是票据本体；其余都是附件。同一文件可同时出现在两处。
   - 飞机=订单确认邮件；酒店=水单；专车=用车行程单；Grab=Member Statement；补助=无。
7. **汇率凭证**：CNY 共用同一张中行牌价截图；MYR 配 Google 汇率截图；USD 配 Google 美元汇率截图；
   HKD 原生不需要。**补助行也要配汇率截图**。

- [ ] 每张汇率截图的币种对与该行原币匹配（SCR 随机码不含币种信息，逐张视觉确认，不臆测）
