# 复核与交付

## 一、录入过程中的逐行校验

每一行保存后立刻验证，不要攒到最后：

```js
const r = await wf.evaluate(() => ({
  hasOfficeIframe: !!document.querySelector('#office-iframe'),   // 票据本体预览
  attachCount: (document.body.innerText.match(/原文件目录\s*\((\d+)\s*份\)/) || [])[1] || null,
  saved: document.body.innerText.includes('保存成功'),
}));
```

| 校验点 | 期望 |
|---|---|
| 票据本体已传 | `#office-iframe` 出现（手录行程除外） |
| 附件份数 | == 该行 `☆附件/` 文件数 |
| 保存提示 | 出现「保存成功」 |
| 金额回读 | 千分位格式化后与计划一致 |

任一不符 → 当场补做，不要继续下一行。

## 二、收尾复核清单

票袋全部行录完后：

- [ ] 票袋名称正确，无重名、无残留空票袋
- [ ] 行数 == 计划行数
- [ ] 票袋内金额合计 == 计划合计（逐行相加，允许 ±0.01）
- [ ] 每行票据本体已传（手录行程除外）
- [ ] 每行附件份数 == 目录附件数
- [ ] 每行开票日期 / 发生日期 / 发生地 / 备注 四项齐全
- [ ] 账单币种全部「港币」
- [ ] 截图留证：票袋列表页 + 每行明细（至少列表页一张全景）

## 三、交付物

1. **进度/明细台账**（Markdown，写在工作目录）：
   逐行表 = 行号 / 消费类型 / 开票日期 / 发生日期 / HKD 金额 / 票据本体 / 附件数 / 状态 / 保存时间。
2. **单页 HTML 报告**（用户偏好）：
   - 单文件、内联 CSS/JS、**零外部依赖**；
   - **浅色主题**、大字号、表格为主；
   - 顶部总览卡（票袋名 / 行数 / 合计金额 / 附件总数 / 完成时间）；
   - 逐行明细表 + 状态标签；
   - 缺口与待确认项单独成块，醒目标注；
   - 表格支持 hover 高亮。
3. 用 `present_files` 交付，**不要提交报销单、不要动报销单表头**。

## 四、交付后提示语（固定）

> 票袋已建好并填完，共 N 行、合计 HK$X,XXX.XX，附件 M 份。
> 后续在差旅费报销单里：发票池（含收据）→「请选择账单」→ 按票袋名筛选 → 勾选 → 确定，即可整袋拉进报销单。
> 报销单的表头填写、TAPL 关联与提交我不代劳，需要时请另行说明。

## 五、空票袋清理

填错或中途被中断会留下空票袋。清理路径：
1. 在左侧栏**选中空票袋**（点票袋行），右侧进入该票袋视图；
2. 工具栏「**更多**」→「**删除**」；
3. 若弹确认对话框，确认即可。

不要在首页「待报销」tab 默认视图（无票袋选中时）下点「更多」——那是顶层操作，不会删票袋。
