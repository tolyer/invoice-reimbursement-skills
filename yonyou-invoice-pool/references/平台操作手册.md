## 1. 导航路径

```
首页 → 发票池（含收据） → 待报销 → 新增 → 填写票袋名称 → 确定
```

### ⚠️ 首次运行必须先做「入口发现」，不要盲点

平台的「发票池（含收据）」入口位置可能随版本/租户变化（左侧导航 / 首页磁贴 / 顶部菜单）。
第一次执行时，先枚举候选入口，连同坐标返回给用户确认，再点击：

```js
const cands = await wf.evaluate(() => {
  const out = [];
  const seen = new Set();
  for (const e of document.querySelectorAll('*')) {
    if (e.children.length !== 0) continue;
    const t = (e.textContent || '').trim();
    if (!/发票池|票据|票袋/.test(t)) continue;
    if (e.offsetWidth === 0) continue;
    let b = e;
    for (let i = 0; i < 4 && b; i++) {
      if (b.tagName === 'BUTTON' || b.tagName === 'A' || /btn|menu|nav|item/i.test(b.className || '')) break;
      b = b.parentElement;
    }
    if (!b || seen.has(b)) continue;
    seen.add(b);
    const r = b.getBoundingClientRect();
    b.setAttribute('data-tb-nav', String(out.length));
    out.push({i: out.length, text: t.slice(0, 24), tag: b.tagName,
              cls: (b.className || '').toString().slice(0, 50),
              x: Math.round(r.x), y: Math.round(r.y)});
  }
  return out;
});
return cands;   // 交给用户确认哪一个
```

确认后用 `await wf.locator('[data-tb-nav="N"]').click();` 点击。
确认过的入口文案记进本文件「环境备注」小节，下次直接点。

### 环境备注（每次成功后补充）

| 租户/环境 | 入口位置 | 已验证 | 备注 |
|---|---|---|---|
| 微众科技（2026-09） | 首页 → 快捷应用区第 1 个磁贴「发票池（含收据）」 | ✅ 2026-09-06 | 进站后默认在「待报销」tab；左侧栏有「票袋」分组；顶部「+ 新增」**是 `div.add`**（侧栏内联生成，**不是弹窗**），自动命名为「票袋N」并立即可重命名 |

### ⚠️ 关键差异（与最初记忆不同）：「+ 新增」不弹窗

- 点击侧栏「账单」标题下的「**+ 新增**」（元素为 `div.add`）后，**直接在侧栏内联生成一个新票袋**，
  自动命名为「票袋N」（N = 当前最大编号 + 1），**该名称 inline 可编辑**——`<input value="票袋N">` 出现在新行里。
- **不是弹窗**，所以脚本不要 `wf.getByText('确定').click()` 或等待 `.wui-modal`。
- 重命名方式：`page.fill()` 直接对那个 input 操作，再 `press('Enter')` 或 `dispatchEvent('blur')` 落库。
- ⚠️ 侧栏 input 的视觉宽度很窄（约 78px），名字超过 ~6 个汉字就会被截断显示，但**实际值会完整保存**。可在工具栏「更多 → 重命名」或选中后再次进入行内编辑修改。
- 进入票袋后工具栏按钮（与报销单内同一套）：**发票采集** | 生成报销单 | 移动 | 转交 | 批改 | 更多；
  **没有显式的「添加账单」按钮**——入口仍是工具栏「**发票采集 ▼**」→「手工录入」/ 扫码 / 邮箱导入。

## 2. 新建票袋（2026-09-06 实测流程）

> ⚠️ 早期记录写的是「弹窗输入票袋名称 → 确定」，**实测不成立**。真实交互是侧栏内联生成 + 行内改名。

1. 进入「发票池（含收据）」，默认落在「待报销」tab；
2. 点左侧栏「账单」分组下的「**+ 新增**」（元素 `div.add`）；
3. 侧栏**内联**生成一行新票袋，自动命名「票袋N」，且该行立刻进入行内编辑态
   —— 新行里会出现一个 `<input value="票袋N">`；
4. 直接对这个 input 改名，回车/失焦落库；
5. 回读侧栏列表，确认票袋出现且名称无误。

```js
// 2. 触发新建
await wf.evaluate(() => { const d = document.querySelector('div.add'); if (d) d.click(); });
await page.waitForTimeout(2000);

// 3+4. 找到新建的 input（value 形如「票袋5」）并改名
const r = await wf.evaluate(() => {
  const inputs = Array.from(document.querySelectorAll('input'))
    .filter(i => i.offsetWidth > 0 && /^票袋\d+$/.test(i.value || ''));
  if (!inputs.length) return 'no-new-pool-input';
  const inp = inputs[inputs.length - 1];
  inp.setAttribute('data-tb-pool-inp', '1');
  return {old: inp.value};
});
await wf.locator('[data-tb-pool-inp]').fill('<票袋名称>');
await wf.locator('[data-tb-pool-inp]').press('Enter');
await page.waitForTimeout(1500);

// 5. 回读校验：按 value 找，不要靠视觉文本（侧栏窄，长名会被截断显示）
const check = await wf.evaluate(() =>
  Array.from(document.querySelectorAll('input'))
    .filter(i => i.offsetWidth > 0 && (i.value || '').includes('<票袋名称>')))
    .map(i => i.value));
```

命名建议：`<行程区间><城市><用途>`，如 `0720-0806吉隆坡差旅`。先列出现有票袋名，避免重名。

### ⚠️ 两个易错点

- **不要等 `.wui-modal`，也不要点「确定」**——没有弹窗，等下去只会超时。
- **校验用 input 的 `value`，不要用侧栏可见文本**。input 视觉宽度约 78px，超过 ~6 个汉字会显示成
  「0720-0806吉…」这类截断，但**值是完整的**；靠文本判断会误判成改名失败。

### ⚠️「新增」的两种语义

- 在**票袋列表（侧栏）**层：新建票袋 ✅ 这里才点。
- 在**账单/票据明细**层：不是新建账单。**新建账单走工具栏「发票采集 ▼」→「手工录入」**。

### 空票袋清理

误建的空票袋：在**左侧栏选中该票袋** → 右侧工具栏「**更多**」→「**删除**」。
不要在未选中票袋的顶层视图点「更多」，那是顶层操作，删不掉票袋。

## 3. 票袋内逐行录入账单（2026-09-06 实测）

先在左侧栏**点选目标票袋**，右侧切到该票袋视图，然后用工具栏入口录账单：

```
左侧栏选中票袋
  → 工具栏「发票采集 ▼」→「手工录入」
  → 选账单类型（小票(非中国大陆) / 手录行程）
  → 选消费类型（飞机 / 住宿（境内/境外）/ 其他交通 / 补助 …）
  → 「下一步」
  → 票据明细表单
```

⚠️ 票袋视图的工具栏是「**发票采集** | 生成报销单 | 移动 | 转交 | 批改 | 更多」，
**没有「添加账单」按钮**——报销单内才有。别去找不存在的「添加账单」。

### ⚠️ 单选按钮要点 label，且必须回读校验

```js
await wf.evaluate(() => {
  const dlg = Array.from(document.querySelectorAll('.wui-modal'))
    .filter(e => e.offsetWidth > 0 && (e.innerText || '').includes('请选择发票类型'))[0];
  const el = Array.from(dlg.querySelectorAll('.wui-radio-label,label,span'))
    .find(e => (e.textContent || '').trim() === '小票(非中国大陆)' && e.offsetWidth > 0);
  if (el) (el.closest('label') || el).click();
});
```

**消费类型默认已选中「飞机」**，改选其他类型会 toggle。选完**必须回读 checked 再下一步**：

```js
const sel = await wf.evaluate(() => {
  const dlg = Array.from(document.querySelectorAll('.wui-modal'))
    .filter(e => e.offsetWidth > 0 && (e.innerText || '').includes('请选择发票类型'))[0];
  return Array.from(dlg.querySelectorAll('[class*=checked]'))
    .map(e => (e.textContent || '').trim().slice(0, 20)).filter(Boolean);
});
// 期望 sel 同时包含账单类型与消费类型，缺哪个补点哪个
```

直接 `wf.getByText('小票(非中国大陆)').click()` 有时会点到页面别处的同名链接——**限定在 `.wui-modal` 内找**。

## 4. 票据明细表单

### 字段清单

| 字段 | 小票(非中国大陆) | 手录行程 | 控件 |
|---|---|---|---|
| 开票日期 / 开票·订单日期 | ✅ | ✅ | 只读 input + wui 日历 |
| 发生日期 | ✅ | ✅ | 只读 input + wui 日历 |
| 含税金额 / 金额 | 含税金额 | 金额 | input，失焦自动千分位 |
| 账单币种 | ✅ | ✅ | 联想输入 |
| 发生地 | ✅ | ❌ 无此字段 | input |
| 备注 | ✅ | ✅ | input |

### ⚠️ 字段定位：优先按 label，坐标只作兜底

把这段塞进 `wf.evaluate`，一次标记全部字段：

```js
const mark = (label, attr) => {
  const norm = s => (s || '').replace(/[*＊:\s]/g, '');
  const nodes = Array.from(document.querySelectorAll('*'))
    .filter(e => e.children.length === 0 && norm(e.textContent) === norm(label) && e.offsetWidth > 0);
  for (const n of nodes) {
    let box = n.parentElement;
    for (let i = 0; i < 5 && box; i++, box = box.parentElement) {
      const inp = box.querySelector('input:not([type=file]),textarea');
      if (inp && inp.offsetWidth > 0) { inp.setAttribute('data-tb', attr); return 'ok:' + attr; }
    }
  }
  return 'fail:' + label;
};
return [mark('开票日期','kpdate'), mark('发生日期','fsdate'), mark('含税金额','hsje'),
        mark('金额','hsje'), mark('账单币种','bizhong'), mark('备注','beizhu'),
        mark('发生地','fashengdi')];
```

坐标兜底（`document.elementFromPoint(x+5,y+5)` 取到 input）——**仅当 label 定位全失败时用**，
换分辨率/换弹窗尺寸即失效，不要写死进脚本。

### 日历：两个面板会残留，每次必须先清标记

## 5. ⚠️ 文件上传：`setInputFiles` 会挂起，必须 JS 注入

Tabbit 运行时里 Playwright 的 `setInputFiles()`（底层 `DOM.setFileInputFiles`）在这个平台上**不返回**，
直接把整次调用卡到超时。改用注入：

```js
const fs = require('fs');                       // nodejs 模式下可用
const b64 = fs.readFileSync(absPath).toString('base64');
const r = await wf.evaluate((s) => {
  const bin = atob(s);
  const bytes = new Uint8Array(bin.length);
  for (let i = 0; i < bin.length; i++) bytes[i] = bin.charCodeAt(i);
  const dt = new DataTransfer();
  dt.items.add(new File([bytes], '文件名.pdf', {type: 'application/pdf'}));
  const input = /* 见下表 */;
  if (!input) return 'no-input';
  input.files = dt.files;
  input.dispatchEvent(new Event('change', {bubbles: true}));
  return {n: input.files.length};
}, b64);
```

| 目标 | 选择器 |
|---|---|
| 票据本体（「上传发票」） | `input[type=file]:not([multiple])` |
| 附件（「原文件目录」→「本地上传」） | `.wui-upload-wrapper input[type=file]`（multiple，可一次多份） |

要点：
- 附件面板有**多个** file input，`.wui-upload-wrapper` 那个才是附件面板的。**注入前先打印所有 input 的父级 class 链确认**。
- 单次 `evaluate` 传的 base64 约 **1.25MB 以内**安全；更大的 PDF 需分片传再在页面内拼接。
- 中文名、`★`/`☆`、`¥` 等字符在部分环节易出问题——**先把文件 cp 到 `/tmp/<短路径>` 再传**（只复制，不动原文件）。
- 上传后**必须回读校验**：附件数看「原文件目录 (N 份)」，票据本体看预览 iframe `#office-iframe` 是否出现。

多个附件一次注入：

```js
const payload = specs.map(([path, name, type]) =>
  ({name, type, b64: fs.readFileSync(path).toString('base64')}));
await wf.evaluate((arr) => {
  const input = document.querySelector('.wui-upload-wrapper input[type=file]');
  const dt = new DataTransfer();
  for (const it of arr) {
    const bin = atob(it.b64);
    const bytes = new Uint8Array(bin.length);
    for (let i = 0; i < bin.length; i++) bytes[i] = bin.charCodeAt(i);
    dt.items.add(new File([bytes], it.name, {type: it.type}));
  }
  input.files = dt.files;
  input.dispatchEvent(new Event('change', {bubbles: true}));
  return {n: input.files.length};
}, payload);
```

## 6. 保存

顺序：**填字段 → 上传票据本体 → 上传附件 → 关闭附件面板 → 保存**。

- ⚠️ 票据本体未上传就点保存，会提示「请在"上传发票"中上传票据」而失败（手录行程/补助除外）。
- 附件面板用「关闭」退出，回到票据明细再点「保存」。
- 保存按钮用 `.wui-modal button` 里 text 为「保存」的最后一个。

### ⚠️⚠️「保存为草稿」≠「保存」

- 「保存为草稿」只把数据丢进**草稿箱**（名称：差旅费报销单草稿+时间戳），**不会落到当前票袋/单据**，
  列表页按单据号搜不到，表单数据整体脱离。
- 一律点「**保存**」。
- 误点了草稿的补救：新建表单 → 顶部「草稿 ▼」→ 选对应草稿恢复 → 再点「保存」。

## 7. 断点续录与防重

- 每完成一行，把 `seq` 写进进度文件（建议 `<工作目录>/.pool-progress.json`），
  记录 `{seq, status, savedAt}`，中断后从第一个未完成 `seq` 继续。
- 恢复前**先读票袋内已有账单列表**，核对行数与金额，避免重复录入产生重行。
- 同一操作连续失败 2 次 → 停止，截图 + 报告当前状态，请求用户协助。
