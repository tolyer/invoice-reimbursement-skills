## 二、字段口径

1. **开票日期**：CNY 消费统一填提交前一天；港币原生消费 / Grab 对账单填实际发生日（对账单出单日）；补助（手录）填出发日。
2. **发生日期**：实际消费发生日——入住日、乘坐日、Grab 首末笔区间、补助填返回日。
3. **账单币种**：一律「港币」，金额 = 原币按汇率折算成 HKD。
4. **金额字段**：小票类填「含税金额」、手录行程类填「金额」，两处均填折算后的 HKD 数值。
5. **发生地**：填城市（如 吉隆坡 / 深圳）；手录行程无此字段。
6. **备注**：必须含换算公式「原币金额/汇率=HKD金额」（CNY 用除法、MYR/USD 用乘法，与折算口径一致）；Grab 行注明附件内容与私人行程剔除。
   - 备注风格：中文逗号、无空格、小写航班号，如「去程zh327,深圳~吉隆坡(含0720携程专车送机),回程zh328,吉隆坡~深圳,汇率为2484/0.8646=2873」。
   - **有退款的行**（2026-10-04 新增）：备注必须写明退款算式，示例：
     「携程订单总额3748,已退款177,实报3571,汇率为3571/0.8584=4160.07」
     **金额字段填退款后净额**，不要填支付金额。
   - **改签行**（2026-10-04 新增）：金额字段填**改签发票 TOTAL（或订单详情页总计）**，**不要填改签后行程单的金额**（不含改签手续费）。备注写清组成，示例：
     「改签订单ORDER-EXAMPLE,原票款4176(机票款2867+税费1309)+改签费1040(手续费450+差价590)=5216,汇率为5216/0.8584=6076.42」
     若只报改签新增部分，备注写：「改签订单ORDER-EXAMPLE,仅报改签费1040(手续费450+差价590,原票款已在XX批次报销),汇率为1040/0.8584=1211.56」
   - **滴滴行**（2026-10-04 新增）：备注写明「行程单金额+高速费=支付金额」，示例：
     「0920 08:36深圳南头跃华园-西北门~宝安国际机场,行程单57.5+高速费9=66.5,汇率为66.5/0.8584=77.47」
     （时间取行程单「上车时间」列，不要用支付时间）
   - **补助行**：写清口径与天数拆解，**必须注明剔除了周末**，示例：
     「20号从深圳出发,20日~8月6日停留在吉隆坡,按工作日计算(剔除周末4天),出发日和到达日各按半天,共13天计975美刀,按照Google汇率计算为7644」
     若区间含节假日且已与用户确认扣除，续写「(已扣除国庆X天)」；若用户确认不扣，写「(含国庆X天,经确认计入)」。
     若**周末 / 节假日加班**且已确认，续写「(其中X月X日周末加班,计入X天)」——出发日或到达日加班仍只记 0.5 天，备注写「(X日出发日加班,按半天计)」。

## 二·补、同一订单 = 一行（2026-10-04 新增，硬性）

> 适用：机票本体 + **改签** + **退款**同时存在一张携程订单时；思路与第二节「专车 C = A + B 合并一行」一致。

**规则：报销单预览表里，一个携程 `ORDER ID` 只占一行。**

| 费用项 | 处理 |
|---|---|
| 机票本金 / 税费 / 燃油附加费 | 计入本行金额 |
| 改签手续费 CHANGEFEE | 计入本行金额（**加项**） |
| 机票差价 PRICE DIFFERENCE | 计入本行金额（**加项**） |
| **退款** | 本行相减（**不做负数行**） |
| 退票手续费 | 本行相减 |
| 多次改签 | 同一行累加，备注里逐次写清 |

```
实报金额 = 原票款支付 + 逐次改签支付 − 已退款 − 退票手续费
```

**票据本体怎么选**（一行只放**一个**本体）：

1. **有退款** → 优先 **订单详情页**（同时露出应付金额与「已退款」，最能自证净额）；
2. **无退款** → **改签发票**（ITINERARY/INVOICE，含 PAYMENT DETAILS 完整拆解）；
3. 其余全部进 ☆附件（同一文件可同时出现在票据与附件中）。

**备注模板（三种场景）**

```
① 只有改签：
改签订单ORDER-EXAMPLE,原票款4176(机票款2867+税费1309)+改签费1040(手续费450+差价590)=5216,汇率为5216/0.8584=6076.42

② 改签 + 退款：
改签订单XXXX,票款4176+改签费1040=5216,后退款2000,实报3216,汇率为3216/0.8584=3745.34

③ 多次改签 + 退款：
订单XXXX,票款4176+0501改签1040+0508改签800=6016,后退款2000,实报4016,汇率为4016/0.8584=4678.47
```

> ⚠️ **检查点**：备注里的净额必须 = 预览表「含税金额」= 实报金额，三者不等就出错了。

## 三、票据本体 vs 附件（原文件目录）

- **票据本体** = 该行能独立证明消费金额与内容的核心凭证，进稽核（每单 ≤ 8 张）；**附件·原文件目录** = 该行全部原始文件（票据源文件 + 支付截图 + 订单凭证 + 汇率截图）。
- 判定规则：**谁能独立证明这笔消费，谁就是票据本体；其余都是附件**。同一文件可同时出现在票据与附件中。
- 常见映射：飞机=订单确认邮件/订单详情页；**机票改签=改签发票（ITINERARY/INVOICE，含 CHANGEFEE 拆解）**；酒店=水单；携程用车=用车行程单；**滴滴用车=滴滴出行行程报销单**；Grab=Member Statement 对账单；出租车=小票；服务类=支付截图；补助=无。
- **改签行的附件固定五件以上**：① 改签费用详情截图（改签费拆解）；② 改签信息截图（新旧航班对照）；③ 改签后行程单；④ 原票款支付截图；⑤ 改签费支付截图；⑥ 中行牌价汇率截图。
- **电子发票一律进附件**（用车电子发票、滴滴电子发票都是附件，不作票据本体）。
- **专车行的两种形态**（由支付凭证勾稽决定，见《账单分类与勾稽规则》第二节第 3 条）：
  - **合并形态**（一笔支付 = 机票 + 专车）：整行挂在飞机名下，票据本体 = 机票订单确认邮件，用车行程单作附件，备注注明「含 MMDD 携程专车送机」。
  - **独立形态**（两笔支付分开）：专车单开一行，账单类型按专车选，票据本体 = 用车行程单，支付截图与中行牌价截图进附件，备注写「原币金额/汇率=HKD金额」。

## 四、汇率凭证搭配

| 行币种 | 汇率凭证 |
|---|---|
| CNY（飞机/**改签**/酒店/专车） | 共用同一张中行牌价截图 |
| MYR（Grab） | 该行配 Google 汇率截图 |
| USD（补助） | 该行配 Google / Morningstar 美元汇率截图（补助也需配，不能省） |
| HKD 原生 | 无需 |

> **跨批次复用汇率截图（2026-10-09 新增）**：某些批次目录里可能**一张汇率截图都没有**（用户只丢了消费凭证进来）。此时不必强补：若该批次处于**同一报销周期内**（取值日相近，通常是提交前后一两天），可以直接**沿用其他批次已归档的那张汇率截图**，方法是把它从上一批次的归档目录复制到本批次行的 `☆附件/` 下。
>
> 三条约束：
> 1. **必须先向用户确认**沿用（连同数值一起念给他核对），不得自行取用；
> 2. 台账「汇率依据」里写明**来源批次的原始文件名**（脱敏示例：`FX-CNY-HKD-EXAMPLE.png`），表明它不是本目录原生文件；
> 3. 汇率**取值日仍须是当期**——跨了报销周期或相隔太久就照常要求用户补新截图。
>
> 脱敏案例：某携程改签批次目录内无汇率截图，经用户确认沿用同一报销周期其他批次的 `FX-CNY-HKD-EXAMPLE.png`（中行折算价 85.84 → ÷0.8584）。

> **补助行附件固定两件**（2026-10-04 新增）：① 美元汇率截图；② **补助逐日台账 txt**。
> 补助行无票据本体，稽核看的就是天数怎么来的，所以逐日明细必须一起上传，
> 内容为「日期 ｜ 星期 ｜ 假期/调休 ｜ 是否加班 ｜ 补助天数 ｜ 说明」每天一行 + 合计行 + 待确认清单。

## 六、平台实操经验（2026-09-05 示例单据填写实录）

**账单录入链路**：发票池（含收据）→「添加账单」→ 请选择账单对话框 →「发票采集」→「手工录入」→ 选发票类型+消费类型（单选，点 label）→ 下一步 → 票据明细表单。
- 「新增」按钮是新建票袋（文件夹），不是新建账单，勿点。
- 消费类型默认选中「飞机」，改选其他类型前注意原选中项会被 toggle。
- 票据明细必填：开票日期/发生日期（wui 日历，readonly，点 td.wui-picker-cell-in-view）/含税金额（自动千分位）/账单币种（输入"港币"联想，点 HKD 行）/发生地/备注。
- **保存账单前必须先在「上传发票」上传票据本体**（手录行程除外），否则提示「请在"上传发票"中上传票据」。
- 附件：表单顶部「附件」按钮 → 附件面板「原文件目录」→ 本地上传（支持多文件、CSV）。

**文件上传（自动化）**：Playwright `setInputFiles` 在 Tabbit 运行时会挂起（CDP DOM.setFileInputFiles 不返回），须改用 JS 注入：
1. Node fs 读文件 → base64（单帧 ~1.25MB 可过传输）；
2. `wf.evaluate` 内 `atob` → Uint8Array → `new File` → `new DataTransfer()` → `input.files = dt.files` → `dispatchEvent(new Event('change',{bubbles:true}))`；
3. 票据本体选 `input[type=file]:not([multiple])`；附件选 `.wui-upload-wrapper input[type=file]`。

**⚠️ 关键坑：「保存为草稿」≠「保存」**
- 「保存为草稿」只存入草稿箱（草稿名称：差旅费报销单草稿+时间戳），**不生成正式单据**，列表页搜不到单据编号，表单数据全部脱离正式单据。
- 正确做法：填完后点「**保存**」，单据以「待提交」状态正式存在（未提交）。
- 补救：新增向导生成新表单 → 表单顶部「草稿▼」→ 选草稿恢复 → 再点「保存」。

**新增向导**：选择交易类型 → 关联事项申请（TAPL 出差申请单，**必填**，未关联将影响保存）→ 生成单据。本次行程对应 TAPL2607060...（2026-07-06 出差申请单），用户确认需勾选关联。

**待办口径**：
- Grab 行「发生日期」为单日期字段，台账口径是首末笔区间（07-20~08-05），本次填末笔 2026-08-05，待用户确认。
- 误触会创建空票袋（票袋3、票袋4），可在请选择账单对话框「更多→删除」清理。
