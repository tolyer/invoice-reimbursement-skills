# 报销单填写逻辑（用友云 YonBIP 差旅费报销单）

> 本文件由用户手工维护。修改后下次执行即生效。
> 最近更新：2026-09-05（依据上期单据 TERD2605270002 逐字段复读结论整理）

## 一、两类账单类型（字段结构不同）

| 账单类型 | 适用 | 字段 |
|---|---|---|
| 小票(非中国大陆) | 飞机、酒店、Grab、专车、服务等 | 账单类型 / 消费类型 / 开票日期 / 发生日期 / **含税金额** / 账单币种 / 备注 / 发生地 |
| 手录行程 | 补助 | 账单类型 / 消费类型 / **开票/订单日期** / 发生日期 / **金额** / 账单币种 / 备注（无发生地、无票据本体） |

## 二、字段口径

1. **开票日期**：CNY 消费统一填提交前一天；港币原生消费 / Grab 对账单填实际发生日（对账单出单日）；补助（手录）填出发日。
2. **发生日期**：实际消费发生日——入住日、乘坐日、Grab 首末笔区间、补助填返回日。
3. **账单币种**：一律「港币」，金额 = 原币按汇率折算成 HKD。
4. **金额字段**：小票类填「含税金额」、手录行程类填「金额」，两处均填折算后的 HKD 数值。
5. **发生地**：填城市（如 吉隆坡 / 深圳）；手录行程无此字段。
6. **备注**：必须含换算公式「原币金额/汇率=HKD金额」（CNY 用除法、MYR/USD 用乘法，与折算口径一致）；Grab 行注明附件内容与私人行程剔除。
   - 备注风格：中文逗号、无空格、小写航班号，如「去程zh327,深圳~吉隆坡(含0720携程专车送机),回程zh328,吉隆坡~深圳,汇率为2484/0.8646=2873」。
   - **补助行**：写清口径与天数拆解，**必须注明剔除了周末**，示例：
     「20号从深圳出发,20日~8月6日停留在吉隆坡,按工作日计算(剔除周末4天),出发日和到达日各按半天,共13天计975美刀,按照Google汇率计算为7644」
     若区间含节假日且已与用户确认扣除，续写「(已扣除国庆X天)」；若用户确认不扣，写「(含国庆X天,经确认计入)」。

## 三、票据本体 vs 附件（原文件目录）

- **票据本体** = 该行能独立证明消费金额与内容的核心凭证，进稽核（每单 ≤ 8 张）；**附件·原文件目录** = 该行全部原始文件（票据源文件 + 支付截图 + 订单凭证 + 汇率截图）。
- 判定规则：**谁能独立证明这笔消费，谁就是票据本体；其余都是附件**。同一文件可同时出现在票据与附件中。
- 常见映射：飞机=订单确认邮件；酒店=水单；专车=用车行程单；Grab=Member Statement 对账单；出租车=小票；服务类=支付截图；补助=无。
- **专车行的两种形态**（由支付凭证勾稽决定，见《账单分类与勾稽规则》第二节第 3 条）：
  - **合并形态**（一笔支付 = 机票 + 专车）：整行挂在飞机名下，票据本体 = 机票订单确认邮件，用车行程单作附件，备注注明「含 MMDD 携程专车送机」。
  - **独立形态**（两笔支付分开）：专车单开一行，账单类型按专车选，票据本体 = 用车行程单，支付截图与中行牌价截图进附件，备注写「原币金额/汇率=HKD金额」。

## 六、平台实操经验（2026-09-05 TERD2609050001 填写实录）

**账单录入链路**：发票池（含收据）→「添加账单」→ 请选择账单对话框 →「发票采集」→「手工录入」→ 选发票类型+消费类型（单选，点 label）→ 下一步 → 票据明细表单。
- 「新增」按钮是新建票袋（文件夹），不是新建账单，勿点。
- 消费类型默认选中「飞机」，改选其他类型前注意原选中项会被 toggle。
- 票据明细必填：开票日期/发生日期（wui 日历，readonly，点 td.wui-picker-cell-in-view）/含税金额（自动千分位）/账单币种（输入"港币"联想，点 HKD 行）/发生地/备注。
- **保存账单前必须先在「上传发票」上传票据本体**（手录行程除外），否则提示「请在"上传发票"中上传票据」。
- 附件：表单顶部「附件」按钮 → 附件面板「原文件目录」→ 本地上传（支持多文件、CSV）。

**文件上传（自动化）**：Playwright `setInputFiles` 在 Tabbit 运行时会挂起（CDP DOM.setFileInputFiles 不返回），须改用 JS 注入：
1. Node fs 读文件 → base64（单帧 ~1.25MB 可过传输）；
2. `wf.evaluate` 内 `atob` → Uint8Array → `new File` → `new DataTransfer()` → `input.files = dt.files` → `dispatchEvent(new Event('change',{bubbles:true}))`；
3. 票据本体选 `input[type=file]:not([multiple])`；附件选 `.wui-upload-wrapper input[type=file]`。

**⚠️ 关键坑：「保存为草稿」≠「保存」**
- 「保存为草稿」只存入草稿箱（草稿名称：差旅费报销单草稿+时间戳），**不生成正式单据**，列表页搜不到单据编号，表单数据全部脱离正式单据。
- 正确做法：填完后点「**保存**」，单据以「待提交」状态正式存在（未提交）。
- 补救：新增向导生成新表单 → 表单顶部「草稿▼」→ 选草稿恢复 → 再点「保存」。

**新增向导**：选择交易类型 → 关联事项申请（TAPL 出差申请单，**必填**，未关联将影响保存）→ 生成单据。本次行程对应 TAPL2607060...（2026-07-06 出差申请单），用户确认需勾选关联。
