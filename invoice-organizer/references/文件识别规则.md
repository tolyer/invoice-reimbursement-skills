# 文件识别规则

> 本文件由用户手工维护。修改后下次执行即生效。
> 最近更新：2026-09-05（依据 0720-0806 吉隆坡出差核销实践整理）

## 一、各类凭证的识别特征

### 1. 携程飞机票
| 文件 | 识别特征 | 关键信息 |
|---|---|---|
| 订单确认邮件 | QQ邮箱打印 PDF，标题含「打印邮件」 | 订单总额、机票/附加服务拆分金额、预订日期 |
| 中英版机票行程单 | 文件名含「行程单」，PDF | 航班号（如 ZH327/ZH328）、起降时间、票价、票号 |
| 支付截图 | IMG_XXXX.PNG，银联/信用卡扣款 | 金额须 = 订单总额；商户名、时间、卡号尾号 |

### 2. 携程酒店
| 文件 | 识别特征 | 关键信息 |
|---|---|---|
| 酒店水单 | 文件名含「水单（订单尾号XXXX）」 | 订单尾号、入住/退房日期、房费总额 |
| 入住证明 | 文件名「入住证明-长串数字」，数字尾 4 位 = 订单尾号 | 入住人、入离日期 |
| 支付截图 | IMG_XXXX.PNG | 金额须 = 水单金额，支付日期 ≠ 入住日期属正常 |

### 3. 携程专车
| 文件 | 识别特征 | 关键信息 |
|---|---|---|
| 用车行程单 | 文件名含「用车行程单」 | 用车时间、上下车点、实付金额、关联航班 |

> ⚠️ **专车是否并入飞机行，取决于支付凭证勾稽，不能默认合并**（2026-09-06 修订）。
> 判定式：`机票订单金额 A` + `专车行程单金额 B` ?= `支付截图金额 C`
> - **C = A + B** → 一笔支付覆盖两项，属同一携程订单 → **合并成一行**（票据本体仍是机票订单确认邮件，专车行程单作附件，备注注明「含 MMDD 携程专车送机」）。
> - **C = A 或 C = B**（两笔支付分开）→ 属两个独立携程订单 → **专车单独成行**（票据本体 = 用车行程单，配自己的支付截图）。
> 详见《账单分类与勾稽规则》第二节第 3 条。

### 4. Grab 流水
| 文件 | 识别特征 | 关键信息 |
|---|---|---|
| Member Statement | 「Consumer _ Grab MY Help Centre.pdf」类对账单 | 逐笔日期/时间/路线/金额、区间合计（MYR） |

### 5. 汇率截图
| 文件 | 识别特征 | 关键信息 |
|---|---|---|
| 中行牌价截图 | SCR-日期-随机码.png，中国银行外汇牌价页 | 港币折算价（如 86.46 → CNY/HKD = 0.8646），用于 CNY 行 |
| Google 汇率截图 | SCR-日期-随机码.png，Google 搜索结果 | 「1 MYR = X HKD」「1 USD = X HKD」字样，用于 MYR / USD 行 |

> ⚠️ **SCR 文件名的随机码不含任何币种信息，禁止凭下载顺序或先验假设归类币种对。**
> 实战教训（2026-09-05）：skfe/sjyj 两张截图被凭假设互换归类——skfe 实为 Google「1 MYR = 1.93 HKD」（Grab 行），sjyj 实为中行牌价（港币折算价 86.46，CNY 行），导致马币汇率截图错放进机票文件夹。
> **强制流程**：逐张打开每张汇率截图视觉确认 → 建立映射表 `文件名 ↔ 币种对 ↔ 数值 ↔ 来源` 写进台账 → 请用户确认映射后再用于归档与折算。

## 二、识别技巧与坑

1. **PDF 文本乱码**：携程/Grab 的 PDF 用自定义字体，pdfplumber 直接抽文本会乱码。改用 `pypdfium2` 高清渲染成图片再视觉读取：
   ```python
   from pypdfium2 import PdfDocument
   page = PdfDocument(path)[0]
   img = page.render(scale=3).to_pil()   # 金额识别用 scale=3，必要时裁剪上下半分别读
   ```
2. **OCR 易错数字**：`3↔8`、`6↔8` 在小字号下易混（实战案例：21.63 误读 21.83、23.69 误读 23.89）。**逐笔加总 ≠ 对账单合计时，先怀疑 OCR，用 scale=3 + 局部裁剪重读，不得强行调平**。
3. **重复文件**：文件名带 ` (1)` 的是浏览器重复下载，内容与原文件一致，核验后标注「留一份」即可。
4. **作废凭证判定**：同一笔消费出现两张金额不同的支付截图时，以「与订单/水单金额一致」的那张为准，另一张标注作废并写明原因（实战案例：IMG_1134 ¥2,624 作废，采用 IMG_1138 ¥2,484 = 机票 2,409 + 专车 75）。
5. **支付金额组合**：一张支付截图可能覆盖多个服务（机票+专车合并扣款），需核对订单拆分金额与扣款总额一致。
