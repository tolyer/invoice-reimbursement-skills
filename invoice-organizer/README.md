# 发票整理助手 · 使用说明

> 一套「先核验、后归档」的差旅报销凭证整理流程。
> 你给材料 → 我出核验台账 → 你确认 → 我才动手整理发票夹。
> **在你确认之前，我不会移动、重命名或删除你的任何原始文件。**

---

## 一、我只受理这 7 类凭证

| # | 类别 | 说明 |
|---|---|---|
| 1 | 携程飞机票 | 订单确认邮件 / 订单详情页、中英版行程单、支付截图（**有退款要按退款后金额报**，见 3.6） |
| 2 | **携程机票改签** | 改签发票 + 改签费用详情 + 改签后行程单 + **两笔支付截图**（**按发票总额报，别按行程单**，见 3.8） |
| 3 | 携程酒店 | 酒店水单、入住证明、支付截图（**每段订单单独一行**） |
| 4 | 携程专车 | 用车行程单 + 用车电子发票（**看支付凭证决定**是否并入飞机行，见 3.4） |
| 5 | 滴滴用车 | 滴滴出行行程报销单 + 滴滴电子发票 + 支付截图（**有高速费要加进去**，见 3.7） |
| 6 | Grab 流水 | Grab Member Statement 对账单 + 逐笔台账 |
| 7 | 出差补助 | 手录行程，无票据本体，只需汇率截图 |

范围外的凭证（如签证费、餐饮发票、地铁票）请先告诉我，确认后再处理。

**币种规则**：消费币种可以是 MYR / CNY / HKD 等，但**报销货币一律 HKD**，**报销单计价货币为 USD**。每一条账单除了消费凭证，还必须附一张「消费币种 → HKD」的汇率截图。

### 3.2 汇率截图（每行都要一张）

| 消费币种 | 汇率来源 | 截图内容 |
|---|---|---|
| CNY（人民币） | 中国银行外汇牌价 | 港币折算价，如 86.46 → 0.8646 |
| MYR（马币） | Google 汇率 | 「1 MYR = X HKD」 |
| USD（美元） | Google / Morningstar 汇率 | 「1 USD = X HKD」（或反向「1 HKD = X USD」，我来换算） |

> ⚠️ **注意报价方向**。有些截图是**反着写**的，例如美元页显示「1 Hong Kong Dollar equals 0.13 United States Dollar」。这种**不能直接用**，我会取倒数换算（`1 USD = 1 ÷ 0.1274 ≈ 7.85 HKD`）——但**反算值绝不直接采用**：我会把算式列出来找你二次确认，或者干脆请你补一张正着写的截图（如「1 USD = 7.85 HKD」）。**最省事的方式：截图时直接搜 `USD to HKD`**，正面报价就不用绕这一圈。
>
> ⚠️ **文件名不可信**。截图叫什么名字都行（`SCR-…` 只是本机截图工具的默认前缀，也可能是 `Screenshot 2026-09-04.png`、`IMG_2201.PNG` 或任何自定义名），**我不会拿文件名来判断这是哪种汇率**——我会逐张打开看内容，再把「文件名 ↔ 币种对 ↔ 数值」映射表列给你核对。这一步请务必看一眼，历史上这里出过错。
>
> 也因此，**凡是没被认作消费凭证的图片，我都会逐张打开确认**，不会因为没有某个前缀就漏掉。你甚至可以把它改名为 `汇率.png` 再给我。

### 3.3 常见的漏项（对照自查）

- [ ] 多段酒店：**每段订单**都要单独的水单 + 入住证明
- [ ] 支付截图金额要和订单/水单金额对得上
- [ ] 有往返机票的，行程单要包含两个航班
- [ ] Grab 对账单要覆盖完整出差区间

缺什么不用怕——直接把现有的给我，我会列出缺料清单告诉你补。

### 3.4 专车：合并成一行，还是单独成行？

**不默认合并，看支付凭证勾稽**（机票金额 A、专车金额 B、支付截图金额 C）：

| 勾稽结果 | 含义 | 我会怎么处理 |
|---|---|---|
| **C = A + B** | 一笔支付同时付了机票和专车 → 同一个携程订单 | **合并成一行**：金额 = A + B，票据本体是机票订单确认邮件，专车行程单作附件，备注注明「含 MMDD 携程专车送机」 |
| **C = A**（专车另有独立支付） | 两笔支付分开 → 两个独立携程订单 | **分别成行**：飞机一行、专车一行；专车行票据本体 = 用车行程单，两行各配自己的支付截图 |

> 所以**专车的支付截图一定要给我**，没有它我没法判断是合并还是拆分，只能停下来问你。

### 3.5 补助：按工作日算，怎么算的

**出差补助只计工作日**，具体是：

| 日期 | 天数 | 说明 |
|---|---|---|
| 出发当天 | **0.5 天** | 逢周末则不计（除非你让我改开关） |
| 中间的**工作日** | 每天 1 天 | **周六、周日一律不计** |
| 落地当天 | **0.5 天** | 同上 |
| 法定节假日 | 暂不自动扣 | **但我会标注出来请你确认**，见下 |

举例——7/20 周一出发、8/6 周四返回，日历上 18 天，但剔除 7/25、7/26、8/1、8/2 两个周末后：

```
0.5 + 工作日12天 + 0.5 = 13 天 × 75 USD = 975 USD
（旧口径含周末是 17 天 / 1,275 USD，差 300 美元）
```

**节假日怎么处理的**：我不替你决定扣不扣。如果出差区间里含有法定节假日，我会在**台账表格里打 ⚠️ 并列出具体日期**（如「2026-10-01 国庆」），请你确认是否计入——这条提醒会写在表格里，不是只在对话里说一句。区间没有节假日的话，台账里会注明「区间内无法定节假日」。

> 想改口径直接跟我说：比如「周末也要算」「节假日要扣掉」「出发日逢周末也算半天」，我改完规则下次就按新的走。

### 3.6 有退款时：按退款后的金额报，不是按支付金额

携程的机票/酒店/用车经常有部分退款。**支付截图上看不到退款**，退款信息只在携程 App「订单详情」页里（「总计」下方那行「已退款 ¥XXX」）。

```
实报金额 = 订单总额 − 已退款金额     （应等于行程单上的金额）
```

举例：机票支付 ¥3,748，订单详情显示「已退款 ¥177」，行程单总计 ¥3,571 → 报销 **3,571**，不是 3,748。

> **所以要给我三样**：① 支付截图 ② **订单详情页（能看到"已退款"那页）** ③ 行程单。
> 只给支付截图的话，我会停下来问你要订单详情页——因为**多报的钱是要退回来的**。

### 3.7 滴滴：高速费要加上

滴滴的行程单金额**不含高速路桥费**，高速费单独在「费用说明」页里（那行「高速路桥费(全额给司机 不参与优惠)」）。

```
实报金额 = 行程单金额 + 高速费 = 支付金额
```

举例：行程单 ¥57.50 + 高速费 ¥9.00 = 支付 ¥66.50 → 报销 **66.50**。

> **所以要给我**：滴滴行程报销单 + **费用说明页** + 电子发票 + 支付截图。
> 只给行程单的话，会少报那 9 块钱——我会主动问你要费用说明页。

### 3.8 机票改签：按「发票总额」报，别按行程单（2026-10-04 新增）

改签订单会给你**两个不一样的总额**，这是最容易报错的地方：

| 金额 | 从哪看 | 含改签手续费吗 | 能不能用来报销 |
|---|---|---|---|
| **发票 TOTAL / 订单详情页「总计」** | 改签发票（ITINERARY/INVOICE）的 PAYMENT DETAILS，或携程 App 订单详情页 | ✅ 含 | ✅ **这才是报销金额** |
| 改签后行程单的「总计」 | 中英版行程单的价格明细 | ❌ **不含** | ❌ 只作附件，**照它会少报** |

举例：发票总计 **¥5,216** = 机票款 2,867 + 税费 1,309 + **改签手续费 450** + 差价 590；而行程单只显示 4,766（少 450）。

> ⚠️ 和退款**方向相反**：退款是「按扣掉退款后的净额报」，改签是「原票款 + 改签费一起报」。
>
> **要给我**：① 改签发票 ② 改签费用详情截图（能看到改期手续费 / 机票差价 / 税差分项那页）③ 改签信息截图（新旧航班对照）④ 改签后行程单 ⑤ **原票款支付截图 + 改签费支付截图两张**。
>
> **我会先问你**：是报**整单**（原票款 + 改签费），还是**只报改签新增的那笔**（改签费 + 差价）——这取决于原票款有没有在别的批次报过，我不替你决定。

**改签 + 退款撞在一起时**（最容易多报的组合）

同一张订单完全可能「先改签、后又退票/部分退款」。麻烦在于：**支付截图看不见退款**、**改签发票是退款之前开的（金额仍是全额）**、**行程单两样都不体现**。

```
实报金额 = 所有支付合计（原票款 + 逐次改签）− 已退款
```

> ⚠️ **改签手续费原则上不退**（携程明写「改期后再退票此费用不退还」），所以退款多半只冲减票款那部分——如果退款金额看起来连手续费也退了，我会标出来找你确认。
> ⚠️ **所以订单详情页一定要给我**。发现缺这张，我会**主动开口要**，不会默默按全额出账。

**同一个订单只会出一行**

票款、改签手续费、机票差价、税费、退款冲减，**全部合并在一条报销记录里**；退款不做负数行，多次改签也只累加、不拆行，只在备注里逐次写清算式。票据本体优先取订单详情页（有退款时）或改签发票（无退款时），其余作附件。

## 五、我会主动停下来问你的九件事

这几件事我不会替你决定：

1. **Grab 疑似私人行程** — 非通勤路线、异常时段的记录（如去巴士站、商场），我会列出来问你要不要剔除；你确认后我在台账标注「私人行程，未计入」。
2. **汇率截图映射表** — 每张截图对应哪个币种对，请你核对确认。
3. **反向报价的汇率** — 如果截图写的是「1 HKD = X 外币」（反的），我会把它反算成「1 外币 = X HKD」并列明算式，但**一定回来找你确认，或请你补一张正着写的截图**；你点头前我不会用它折算。**反算值绝不直接采用。**
4. **作废 / 重复凭证** — 同一笔消费出现两张金额不同的支付截图时，我会说明判断依据（以与订单金额一致的为准），请你拍板。
5. **专车合并还是单独成行** — 我会给出勾稽算式（机票 A + 专车 B ?= 支付 C）和结论，请确认。没有专车支付截图时我会直接问你。
6. **出差区间含法定节假日** — 补助默认不扣节假日，但我会在台账表格里打 ⚠️ 列出具体日期，请确认扣还是不扣。
7. **退款 / 高速费看不全** — 只要我判断可能发生退款（携程类），或滴滴行程单存在高速费，我会直接问你要「订单详情页」「费用说明页」，不给就停在这一步。
8. **周末 / 节假日有没有加班**（2026-10-04 新增）— 出差区间里每一个周末日和法定节假日，我都会单独问你「那天加班了吗」：
   - 答「**加班**」→ 那天**照计补助**（若那天正好是出发日或到达日，仍只算半天）；
   - 答「没加班」→ 周末计 0 天，节假日按你之前定的扣或不扣来。

   我不会默认你周末没加班就定稿。行里的「是否加班」列会先写「待确认」，等你逐天答复后再重算。

   答「这几天上班了」这种笼统说法时，我会先把候选日期列出来请你勾选（比如「25/26/27 是哪几天？」），避免把天数算错。
9. **改签订单：报整单还是只报改签费，以及缺料我会主动开口要**（2026-10-04 新增）—
   - **口径**：我会先跑完勾稽（原票款支付 = 机票款 + 税费；改签支付 = 改期手续费 + 差价；两笔合计 = 发票总额），再问你报**整单**（含原票款）还是**仅改签新增部分**——原票款有没有在别的批次报过，只有你知道；
   - **一行合并**：同一个订单的票款 + 改签费 + 差价 + **退款**，合并成**一条记录**的净额，**退款不做负数行**，多次改签也只累加；票据本体优先取订单详情页（有退款时）或改签发票（无退款时）；
   - **缺料我主动要**（不等你问）：改签发票 / 改签费用详情截图 / 新旧航班对照 / **订单详情页** / 逐笔支付截图 / 改签后行程单。**尤其订单详情页——退款只在那里露出，没它我查不出退款，会直接多报。**
